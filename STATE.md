# Состояние порта UEFI и Windows on ARM на TB-J606F (2026-11-10)

## Кратко
- UEFI **v8** в `boot_a` (записан 09.11). Меню J606fBoot выбирает Windows или Linux, по умолчанию грузится Windows.
- Windows 11 Pro ARM64 (22621) установлена на внутреннюю память и грузится до рабочего стола.
- В Windows работают:
  - **Wi-Fi** — настоящий адаптер 802.11ac, WPA2-Personal, автоподключение ([notes/windows_wifi.md](docs/notes/windows_wifi.md));
  - **Bluetooth** — стек Microsoft; сопряжение мыши проверено, звук через Bluetooth-наушники работает (подтвердил владелец);
  - **USB host** — мышь и клавиатура через OTG, только USB 2.0 (служба `j606fusbc`, автозапуск);
  - **яркость экрана** — ползунок Windows через драйвер `j606fdsp` (display-only, без 3D; подтвердил владелец);
  - тач (10 касаний), кнопка питания, батарея и адаптер, зарядка, **частоты CPU** (служба `j606fcpu`).
- Запущены **ADSP** (аудиопроцессор) и **модем** из Windows. Встроенного звука (динамики) и датчиков пока нет: нужен канал GLINK к ADSP.
- Разработка идёт без перезагрузок: компьютер разработчика подключается к Windows по Bluetooth через одноплатный компьютер
  ([docs/DEV_WITHOUT_REBOOT.md](docs/DEV_WITHOUT_REBOOT.md)).

## Версии UEFI
| Версия | Что изменилось | Статус |
|---|---|---|
| v3 | первая RELEASE для Windows | проверена |
| v4 | `EnableChargerWdog = 0` | проверена |
| v5d | батарея по SPMI в AML | проверена |
| v6 | устройство тача `TSC0` (`JHMX0001`) | проверена, тач работает |
| v7 | резерв памяти pmOS; меню J606fBoot | проверена |
| v8 | SSDT с устройством дисплея (`JDSP0001`); сборка без приложения MassStorage | в `boot_a` (09.11), проверена |

Запись в `boot_a` выполнена через fastboot: записать UEFI из Windows нельзя, защита SAN не даёт писать в загрузочные диски.

## Не работает или не сделано
- Встроенный звук (динамики). Звук через Bluetooth работает.
- Датчики, камеры, перо, сон, ускорение GPU, часы (RTC).
- Wi-Fi: один поток (потолок 433 Мбит/с), обрыв виден только по деаутентификации, энергосбережение радио выключено.
- Bluetooth: скорость UART 3 Мбит/с включается флагом `bt3m.on`, сон BT отключён.
- Кнопки громкости без аудиодрайвера дают только отчёты.
- Дисплей: только display-only, 3D-ускорения нет.

## Ограничения
- `FVMAIN` должен оставаться **0x521000**: при 0x522000 образ не грузится (причина не найдена).
- Windows 24H2 и новее на SD662 не стартует.
- NTFS после принудительного выключения грязная: перезагружайте Windows штатно.
