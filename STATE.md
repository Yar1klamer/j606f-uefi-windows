# Состояние порта UEFI и Windows on ARM на TB-J606F (2026-11-08)

## Кратко
- UEFI v7 в `boot_a`. Меню J606fBoot выбирает Windows или Linux. По умолчанию грузится Windows.
- Windows 11 Pro ARM64 (22621) установлена на внутреннюю память и грузится до рабочего стола.
- Работают: UFS, рабочий стол на кадровом буфере UEFI, батарея и адаптер, зарядка, тачскрин (свой HID-драйвер, 10 касаний), кнопка питания,
  **частоты CPU** (служба `j606fcpu`), **Bluetooth** (стек Microsoft; звук через Bluetooth-наушники работает, подтвердил владелец), **USB host** (контроллер поднимается, проверка устройств через OTG продолжается).
- **Wi-Fi работает**: Windows видит настоящий адаптер Wi-Fi (WPA2-Personal, автоподключение, 802.11ac до 80 МГц). Подробно — [notes/windows_wifi.md](docs/notes/windows_wifi.md).
- Запущены **ADSP** (аудиопроцессор) и **модем** из Windows. Встроенного звука (динамики) и датчиков пока нет: нужен канал GLINK к ADSP.
- Разработка идёт без перезагрузок: компьютер разработчика подключается к Windows по Bluetooth через одноплатный компьютер
  ([docs/DEV_WITHOUT_REBOOT.md](docs/DEV_WITHOUT_REBOOT.md)).

## Очерёдность работ (решение владельца, 08.11)
1. USB — отложено.
2. Bluetooth — сделано, остались доработки (см. ниже).
3. Wi-Fi — сделано (настоящий адаптер, WPA2, автоподключение, 802.11ac).
4. Частоты CPU — сделано.
5. Сон.
6. Встроенный звук (динамики). Звук через Bluetooth уже работает.
7. Камеры.
8. Датчики.
Дисплей с ползунком яркости отложен.

## Версии UEFI
| Версия | Что изменилось | Статус |
|---|---|---|
| v3 | первая RELEASE для Windows | проверена |
| v4 | `EnableChargerWdog = 0` | проверена |
| v5d | батарея по SPMI в AML | проверена |
| v6 | устройство тача `TSC0` (`JHMX0001`) | проверена, тач работает |
| v7 | резерв памяти pmOS; меню J606fBoot | в `boot_a`, проверена |
| v8 | SSDT с устройством дисплея (`JDSP0001`); сборка без приложения MassStorage | только `fastboot boot`; в `boot_a` не записана |

## Не работает или не сделано
- Дисплей с ползунком яркости: драйвер `j606fdsp` выводит рабочий стол на внешнем мониторе, на встроенной панели Windows помечает адаптер ошибочным (код 43). Отложено.
- Встроенный звук (динамики), датчики, камеры, перо, сон, GPU-ускорение, часы (RTC). USB host: контроллер поднимается, проверка устройств через OTG продолжается.
- Wi-Fi: один поток (потолок 433 Мбит/с), обрыв виден только по деаутентификации, энергосбережение радио выключено.
- Bluetooth: сопряжение мыши не проверено; скорость UART 3 Мбит/с включается флагом `bt3m.on`, сон BT отключён.
- Кнопки громкости без аудиодрайвера дают только отчёты.

## Открытые вопросы
- Лицензии: `windrv/touch` и `windrv/hidtouch` — GPL-2.0-only; `windrv/j606fdsp` — MIT.
- Ветка `english` в публичном репозитории пока не обновлена.
- Файл `windrv/j606fdsp/patch_kmdod.sh` в публичной копии остаётся прежним, потому что новая версия не проверена.

## Ограничения
- `FVMAIN` должен оставаться **0x521000**: при 0x522000 образ не грузится (причина не найдена).
- Windows 24H2 и новее на SD662 не стартует.
- NTFS после принудительного выключения грязная: перезагружайте Windows штатно.
