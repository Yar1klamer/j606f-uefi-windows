# Состояние порта UEFI и Windows on ARM на TB-J606F (2026-11-07)

## Кратко
- UEFI v7 в `boot_a` (проверен на устройстве); меню J606fBoot выбирает Windows или Linux.
- Windows 11 Pro ARM64 (22621) установлена на внутреннюю память и грузится до рабочего стола.
- Работают: UFS, рабочий стол на кадровом буфере UEFI, батарея и адаптер, зарядка, **тачскрин** (свой HID-драйвер, 10 касаний), кнопка питания.
- Громкость даёт отчёты, но звука нет. Яркость панели доказана на уровне DSI; свой дисплейный драйвер в работе и пока не запускается.

## Версии UEFI
| Версия | Что изменилось | Статус |
|---|---|---|
| v3 | первая RELEASE для Windows | проверена |
| v4 | `EnableChargerWdog = 0` | проверена |
| v5d | батарея по SPMI в AML | проверена |
| v6 | устройство тача `TSC0` (`JHMX0001`) | проверена, тач работает |
| v7 | резерв reserved-memory для GPU и ADSP Linux; меню J606fBoot | в `boot_a`, проверена |

## Не работает или не сделано
- Дисплейный драйвер с ползунком яркости: драйвер стартует, но Windows помечает адаптер ошибочным. Работа продолжается.
- Перо, звук, Wi-Fi, Bluetooth, ускорение GPU, USB host, камеры, датчики.
- Часы (RTC) стоят на 2022 году, сон не настроен, частоты CPU не меняются.
- Кнопки громкости без аудиодрайвера дают только отчёты.

## Открытые вопросы
- Лицензии решены владельцем: `windrv/touch` и `windrv/hidtouch` — GPL-2.0-only, `windrv/j606fdsp` — MIT.
- **Ветка `english`** не создана, ссылка на неё в README остаётся до решения владельца.
- `windrv/hidtouch` — последняя версия работает на устройстве; перо не реализовано.

## Ограничения
- `FVMAIN` строго `0x521000`: при `0x522000` образ не грузится (причина не найдена).
- Windows 24H2 и новее на SD662 не стартует.
- NTFS после принудительного выключения грязная; перезагружайте Windows штатно.
