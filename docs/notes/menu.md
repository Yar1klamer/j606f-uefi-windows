# Меню выбора ОС J606fBoot

J606fBoot — отдельное UEFI-приложение, которое выбирает между Windows и Linux (postmarketOS). Исходники: `uefi/Platforms/Lenovo/j606fPkg/Application/J606fBoot/`
(`J606fBoot.c`, `Inflate.c`, `Inflate.h`, `J606fBoot.inf`).

## 1. Зачем оно нужно
Раньше UEFI грузил только Windows. Меню переключает загрузку без пересборки UEFI и без записи в загрузочные разделы Lenovo.
Меню вынесено в ESP, а не в FV прошивки, потому что FVMAIN заполнен почти полностью (см. [port_plan.md](port_plan.md), раздел 5.1).

## 2. Как оно запускается
- Mu-Silicium запускает `Internal Storage`, в ESP ищется `\EFI\Boot\bootaa64.efi`. Наше меню лежит там под этим именем.
- Исходный загрузчик Windows (`bootmgfw.efi`) сохраняется рядом как `\EFI\Boot\bootaa64.windows.efi`. Меню грузит его через путь
  `\EFI\Microsoft\Boot\bootmgfw.efi` того же раздела.
- Откат: вернуть `bootaa64.windows.efi` в `bootaa64.efi`. Тогда ESP загружает Windows напрямую, меню не появляется.

## 3. Управление и экран
- Экран: два пункта — «Windows on ARM, UEFI» и «Linux from boot_b».
- Громкость + и − выбирают пункт, **Питание** (Enter) загружает выбранный.
- Тайм-аут `MENU_TIMEOUT_S = 5` секунд: без нажатий загружается пункт по умолчанию. Первое нажатие отключает тайм-аут.
- Последний выбор хранится в `\EFI\Boot\j606fboot.def`: символ `0` — Windows, `1` — Linux. Файл читается при старте и обновляется при загрузке.

## 4. Как грузится Linux
1. Меню читает раздел `boot_b` (стоковый Android-образ). Проверяется заголовок: версия 2, размер страницы, размеры ядра, ramdisk и DTB.
2. Ядро в образе сжато gzip; `Inflate.c` распаковывает его (свой декодер по структуре puff.c, без чужого кода). Ядро должно быть EFI-stub (`MZ`-заголовок).
3. Секция DTB образа устанавливается как FDT configuration table (сам DTB проверяется по сигнатуре).
4. Ramdisk передаётся через `LoadFile2` с GUID `LINUX_EFI_INITRD_MEDIA_GUID`.
5. Ядро запускается с командной строкой из образа.
Ничего не записывается на диск; меню только читает `boot_b`.

## 5. Журнал
Меню пишет журнал в `\EFI\Boot\j606fboot.log`. Файл перезаписывается при каждом старте. Его удобно читать из Linux, смонтировав ESP только для чтения.

## 6. Метка перезагрузки для pmOS
Перед перезагрузкой в Linux меню ставит в раздел `misc` метку `J606F-REBOOT` по смещению `0xF0000`. Initramfs pmOS читает её
и грузит систему нормально, а не показывает «Hold Power to boot»: перезагрузка иначе выглядит для PMIC как подача питания от кабеля.
Это единственная запись меню в раздел, не относящийся к ESP.

## 7. Ограничения
- Меню не проверяет подпись Linux-образа (Secure Boot на устройстве не используется).
- Заголовок boot-образа версии 2 поддерживается только такой, как в стоковом `boot_b`.
- Меню не поддерживает выбор нескольких ядер или ramdisk, кроме одного в образе.
