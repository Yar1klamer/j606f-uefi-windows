# Wi-Fi в Windows на J606F

Статус на ноябрь 2026: **Wi-Fi работает в Windows.** Адаптер виден как обычный беспроводной адаптер: значок, список сетей, ввод пароля,
WPA2-Personal, автоподключение после перезагрузки. Поддерживаются 802.11a/b/g/n/ac, один поток, полоса до 80 МГц.

## 1. Что проверено
- Сеть 5 ГГц: приём около 280 Мбит/с, передача около 230 Мбит/с (потолок одного потока — 433 Мбит/с).
- Отключение и повторное подключение, автоподключение после перезагрузки.
- Сканирование: список сетей в Windows, пассивное сканирование по 38 каналам.

## 2. Как устроено в Windows
| Элемент | Что это |
|---|---|
| Модем и WLAN-прошивка | запускаются через ту же схему, что ADSP (см. [windows_adsp.md](windows_adsp.md)): TrustZone, SMEM, SMP2P |
| `btbus` | шина для удалённых процессоров: QRTR, rmtfs (EFS модема только в оперативной памяти), pd-mapper, TFTP, QMI WLFW, CE, HTC и WMI |
| `j606fwifi` | минипорт Native 802.11 (NDIS 6.30, ExtSTA). Подключением, значком и WPA2-рукопожатием управляет сама Windows (WlanSvc) |
| `j606fnet` | прежний вариант минипорта Ethernet, оставлен для сравнения |
| Связка | `\Callback\J606fWlan`: между `btbus` и минипортом ходят кадры Ethernet, минипорт преобразует их в 802.11 и обратно |
| Устройство | `ROOT\NET\0001` из встроенного `netvwifimp.inf`; сервис заменён на `j606fwifi`. Для привязки нужен `LowerRange = wlan`, иначе фильтр `nwifi` не подключается |

Что делает `btbus` в ходе подключения: создаёт виртуальный интерфейс (vdev), отправляет аутентификацию и ассоциацию через WMI,
настраивает пира (peer). Ключи CCMP приходят от Windows через `OID_DOT11_CIPHER_KEY_MAPPING_KEY` и `OID_DOT11_DEFAULT_KEY`
и передаются в прошивку. Минипорт ведёт таблицу найденных сетей (до 40 записей) и выбирает лучшую точку нужного SSID.

## 3. Скорость: что дало результат
1. **Калибровка радио.** Загруженная калибровка (board data) определяет, какие скорости радио держит. Общий файл из открытого набора
   linux-firmware давал около 65 Мбит/с (VHT80 MCS 2), калибровка с самого устройства — около 280 Мбит/с (MCS 9). Для хорошей скорости нужна калибровка
   со своего устройства (файл частный, в репозиторий не входит); с общей калибровкой скорость примерно в 4 раза ниже.
2. HT и VHT в запросе ассоциации и в настройке пира, режим канала в запуске vdev, разрешённые скорости в списке каналов.
3. WMM и TID 0 для одноадресного трафика. Без QoS-приоритета прошивка не объединяет кадры.
4. Опрос очередей без прерываний, пока идёт трафик. Кольцо приёма на 1024 записи, очереди передачи 256 и 128.
5. Индикатор качества: раз в 2 секунды драйвер сообщает `NDIS_STATUS_DOT11_LINK_QUALITY`. Без него Windows показывает слабый сигнал.

Режим HT и VHT можно выключить файлом на устройстве (без пересборки драйвера).

## 4. Ограничения
- Один поток (чип работает 1×1): потолок канала 433 Мбит/с.
- Потеря маяков не определяется; обрыв виден только по сообщениям деаутентификации и дисассоциации.
- Энергосбережение радио выключено на время связи: расход выше, сон — отдельная задача.
- Прерываний от CE нет: под нагрузкой одно ядро занято опросом.
- В `netsh` адаптер называется по шаблонному имени минипорта; описание — «J606F Wi-Fi».

## 5. Настройка и безопасность
- Имя сети и пароль задаются файлом настроек на устройстве. В репозитории их нет, в журналы они не попадают.
- Поддерживается только WPA2-Personal (PSK) с шифрованием CCMP.
- MAC-адрес адаптера локально администрируемый, создаётся один раз и хранится в параметрах сервиса. В публичные материалы не попадает.
- Журналы содержат только счётчики, номер канала, уровень сигнала и длину SSID. MAC, BSSID и сам SSID в журналах не пишутся.

## 6. Что это значит для других подсистем
Шаги, которые понадобились для Wi-Fi, одновременно решают инфраструктуру удалённых процессоров: загрузка модема, GLINK к модему,
QRTR, rmtfs, pd-mapper, TFTP. Для звука и датчиков нужен тот же GLINK, но к ADSP.

## 7. Прошивки и данные
Прошивки модема и WLAN, калибровка и образы разделов модема — блобы Lenovo и Qualcomm. В репозитории их нет: получаются со своего устройства.
Правило проекта: разделы модема (`modemst*`, `fsg`) только читаются, запись делается только в копии в оперативной памяти.
